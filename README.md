# Superstore Sales Executive Dashboard

An end-to-end Data Analytics project connecting a local MySQL database with Power BI Desktop to build an interactive business intelligence tracking engine.

## 🚀 Key Features & Architecture
- **Data Source:** MySQL Relational Database (`sales_project`)
- **ETL Pipeline:** Transformed and cleaned native data using Power Query Editor.
- **DAX Calculations:** Built custom enterprise measures for Business Health Tracking:
  - `Total Revenue = SUM(sales)` -> **$2.30M**
  - `Total Profit = SUM(profit)` -> **$286.40K**
  - `Profit Margin % = DIVIDE(Total Profit, Total Revenue, 0)` -> **12.47%**

## 📊 Dashboard Insights
- **Top Regional Performer:** West Region dominates sales revenue.
- **Profit Engines:** Copiers ($55.62K) and Phones ($44.52K) yield the highest corporate net profit.
